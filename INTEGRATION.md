# Как развернуть у себя

Страница одна, без сборки и зависимостей: открывается файлом, кладётся любым
статическим сервером. Всё, что нужно, — отдать её по https и поднять один
эндпоинт.

## Что в архиве

| Файл | Зачем |
|------|-------|
| `index.html` | Прототип: с панелью состояний и заглушкой бэка. Для показа. |
| `production/index.html` | То же без демо-обвязки, с реальным `fetch`. Отсюда начинать. |
| `build-production.py` | Пересобирает `production/` из `index.html` после правок дизайна |
| `.htaccess` | Только для Apache — снимает `X-Frame-Options`, см. ниже |
| `README.md` | Почему экран устроен именно так. Читать перед тем, как менять |
| `bot/` | Бот: кабинет, разделы, триал на `/start`, напоминания. `bot/README.md` |
| `bot-setup.py` | Привязка мини-аппы к боту через Bot API, без пароля |

Посмотреть локально (по `file://` не заработает — Telegram SDK не подгрузится):

    python3 -m http.server 8000
    # http://localhost:8000/production/index.html

Без бэка страница честно покажет «Не удалось загрузить» с кнопкой «Повторить» —
это рабочее состояние, а не поломка.

## Шаг 1. Эндпоинт

Один запрос, `GET /miniapp/status`. Адрес задаётся константой `API_URL`
в начале скрипта.

Авторизация — заголовком `X-Telegram-Init-Data`, туда кладётся `tg.initData`.
**Подпись обязательно проверять на сервере** по алгоритму из документации
Telegram: HMAC-SHA256 с ключом `HMAC-SHA256("WebAppData", bot_token)`.
Идентификатор пользователя брать только из проверенных данных — то, что
пришло в теле запроса, доверия не заслуживает.

Ответ:

```json
{
  "expires_at":        "2026-12-14T21:40:00Z",
  "unlimited":         false,
  "period_days":       180,
  "subscription_url":  "https://sub.example.com/<key>",
  "config_fetched_at": "2026-09-04T18:22:11Z",
  "last_client":       "INCY"
}
```

| Поле | Что делает на экране |
|------|----------------------|
| `expires_at` | дата под заголовком и остаток на шкале |
| `unlimited` | вместо даты «Бессрочная», на шкале `∞` |
| `period_days` | длина оплаченного периода — от неё считается заполнение шкалы |
| `subscription_url` | ссылка, которую отдаём приложению и копируем вручную |
| `config_fetched_at` | **главное поле**, см. ниже |
| `last_client` | подставляется в «INCY получил подписку» |

### Про `config_fetched_at`

На нём держится весь мастер подключения. Мини-апка живёт в вебвью Telegram и
**не может надёжно узнать, открылось ли внешнее приложение**: `visibilitychange`
и `blur` ведут себя по-разному на iOS, Android и десктопе, а после `openLink`
мини-апка обычно сворачивается и при возврате поднимается заново, с чистой
страницей. Поэтому она не следит за приложением, а спрашивает сервер: забрали
конфиг по ссылке подписки или ещё нет.

В Remnawave это есть из коробки — панель фиксирует обращение к ссылке подписки
вместе с user-agent. Нужно отдать наружу время последнего обращения и клиент.

Отсюда два поведения:

- после «Добавить подписку» экран опрашивает статус раз в 2.5 секунды и сам
  показывает «Готово», когда конфиг забрали. Через 30 секунд без результата
  ведёт на ручной путь. Константы `POLL_EVERY` и `GIVE_UP_AFTER`;
- если поле не пустое **при открытии**, значит человек всё настроил раньше —
  мастер не показывается вовсе, экран открывается сразу на «Готово».

Если поле возвращать всегда `null`, экран не сломается, но каждый раз будет
доходить до «Пока не видим подписку» — то есть смысл всей конструкции пропадёт.

## Шаг 2. Ссылки наружу

Три константы в начале скрипта:

```js
const API_URL      = '/miniapp/status';
const DOWNLOAD_URL = (device) => '...';  // device: ios | android | macos | windows | linux | tv
const OPEN_APP_URL = (app)    => '...';  // app: incy | happ
```

**Схемы вроде `happ://` из вебвью бросать нельзя** — скорее всего не сработает.
`DOWNLOAD_URL` и `OPEN_APP_URL` должны отдавать обычные https-адреса на вашем
домене, а редирект на схему пусть делает внешний браузер, куда уводит
`tg.openLink`. Проверять надо вживую: iOS, Android, macOS-клиент и Telegram
Desktop ведут себя по-разному.

## Шаг 3. Оплата

Кнопка «Продлить подписку» сейчас показывает тост — функция `renew()`.
Внутри мини-аппы это `tg.openInvoice(url, callback)`, ссылку на счёт выдаёт бэк.
Telegram Stars на бэке уже есть.

## Шаг 4. Хостинг

Отдавать по https, кодировка `utf-8`. Одна тонкость: **Telegram Web открывает
мини-аппы в iframe**. Если сервер отдаёт `X-Frame-Options: SAMEORIGIN` —
на десктопе в браузере страница не откроется. Мобильные клиенты используют
вебвью, их это не касается, поэтому баг легко пропустить. Приложенный
`.htaccess` снимает заголовок для Apache; для nginx —
`proxy_hide_header X-Frame-Options` или не выставлять его на этом пути.

Затем прописать адрес в @BotFather как Web App.

## Чего в прототипе нет

- экрана с тарифами для нового пользователя: все состояния предполагают, что
  подписка когда-то была;
- QR со ссылкой подписки для настройки на другом устройстве — особенно нужен
  для Android TV, где ссылку набирают пультом;
- реальных диплинков и оплаты.

## Если правите дизайн

Правьте `index.html` (прототип), затем `python3 build-production.py` — он
пересоберёт `production/index.html`, вырезав панель состояний, корпус телефона
и заглушку бэка. Скрипт падает с внятной ошибкой, если разметка изменилась так,
что он не нашёл нужный кусок, — молча кривой файл не соберётся.
