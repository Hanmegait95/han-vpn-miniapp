# Бот Han VPN — прототип

Long polling, без зависимостей, без вебхуков. Запускается одной командой
на любой машине с Python 3:

    python3 -u bot/bot.py

Токен бота — в `~/.config/hanvpn/bot_token` (см. `bot-setup.py` в корне).
Доступы к Remnawave — в `~/.config/hanvpn/remnawave.json`; без них бот
работает, просто не знает про подписки.

| Файл | Что делает |
|------|------------|
| `bot.py` | Механика: опрос Telegram, отрисовка экранов, напоминания |
| `screens.py` | Содержимое: тексты, кнопки, переходы. Правки — сюда |
| `remnawave.py` | Тонкий клиент панели, повторяет логику вашего бэкенда |
| `store.py` | Память: чат, живая карточка, отметки о напоминаниях |

## Как устроен поток

**Одна живая карточка.** Бот не шлёт новое сообщение на каждое нажатие,
а перерисовывает то же самое — баннер, подпись и кнопки. При `/start`
предыдущая карточка удаляется. В чате всегда ровно один актуальный экран.

**Два первых экрана для двух разных людей.** `home()` в `screens.py`
выбирает по факту «подключался ли когда-нибудь»:

- `welcome` — новичок. Рассказ, что это, три дня бесплатно, одна кнопка
  «Подключить». Ни ID, ни баланса — ему они ни о чём.
- `cabinet` — тот, кто уже подключался. Статус соединения, дата, продление.

**Триал выдаётся молча на `/start`.** Кнопки «активировать» нет: человек
пришёл за VPN, спрашивать, хочет ли он попробовать, незачем. Повторный
`/start` находит существующую учётку — Remnawave привязывает её
к telegram id, накрутить не выйдет. `ensure_trial()` в `bot.py`.

**Кабинет говорит о соединении, а не о дате.** Подписка и соединение —
разные вещи; человек хочет знать второе. `connection_line()`:

| Данные из Remnawave | Экран | Главная кнопка |
|---|---|---|
| `subLastOpenedAt` пуст | ⚠️ Устройство ещё не настроено | 🔌 Подключить |
| `onlineAt` < часа назад | 🟢 Подключено · были онлайн N мин назад | 🛒 Продлить |
| `onlineAt` давно | 🟡 Соединения не было N дн назад | 🛒 Продлить |

**Инструкции живут в одном месте — в мини-аппе.** Экран «Инструкции»
в боте только выбирает устройство и открывает мини-аппу сразу на нём:
`?platform=ios`. Иначе текст в боте и мастер в мини-аппе разойдутся.

**Бот отвечает на любой текст.** Молчание выглядит поломкой. По приметам
ведёт в раздел: «не работает» → поддержка, «продлить» → тарифы,
«настроить» → инструкции, остальное → домой.

**Бот пишет первым.** Фоновый обход раз в 15 минут (`notifier()`), три
повода: взял подписку и через час не настроил устройство; осталось меньше
суток; кончилась. У каждого напоминания ключ, привязанный к дате окончания:
в одном периоде уходит один раз, после продления — снова актуально.
Без Remnawave данных нет, и обход молчит.

## Экраны

    welcome ─┬─ 🔌 Подключить (мини-аппа)
             ├─ 📘 Инструкции ─── устройство → мини-аппа ?platform=
             └─ 💬 О сервисе ─┬─ 🔌 Как подключить (мини-аппа)
                              ├─ 💳 Тарифы    📘 Инструкции
                              ├─ 💬 Поддержка   (здесь ID для обращения)
                              ├─ 📣 Канал
                              └─ 📄 Условия
    cabinet ─┬─ 🛒 Продлить / 🔌 Подключить   (что нужнее сейчас)
             ├─ 🤝 Партнёрская программа
             └─ 📘 Инструкции   💬 О сервисе

Все подписи укладываются в лимит Telegram 1024 символа — проверяется
скриптом перед запуском (см. историю коммитов).

## Ограничения прототипа

- Память в JSON-файле. В бою — таблица `VpnUser` и журнал уведомлений.
- Серверы Telegram не достают до российского хостинга, поэтому баннеры
  грузятся файлом, а не по ссылке, и кэшируются по `file_id`.
- Вебхуки на Timeweb не поднять по той же причине; long polling работает
  откуда угодно.
